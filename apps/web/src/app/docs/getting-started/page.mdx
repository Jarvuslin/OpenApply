# Getting started with OpenApply

OpenApply is currently a local development MVP. Follow the [repository README](https://github.com/Jarvuslin/OpenApply#setup) for Windows with WSL2 or the Mac beta with Lima.

You need Git, Bun, Node.js, .NET 10, the appropriate VM runtime and an authenticated Claude Code account. Run `node scripts/openapply.mjs doctor` to check your machine. The README covers the database, persistent browser VM, encrypted configuration, first local account and Gmail connection. Mac support awaits real-device acceptance testing.

Start with a preparation-only trial and review the résumé and missing answers. A complete unattended application has not yet passed testing. CAPTCHA solving is disabled.

The internal plugin namespace remains jobpilot for compatibility with the inherited runtime. The upstream JobPilot marketplace installer is not an OpenApply installer.
