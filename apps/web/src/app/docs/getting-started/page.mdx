# Getting started with OpenApply

OpenApply is currently a local development MVP. Follow the [repository README](https://github.com/Jarvuslin/OpenApply#clone-and-setup-windows) to clone and configure it on Windows with WSL2.

You need Git, Bun, Node.js, .NET 10, WSL2 and an authenticated Claude Code account. The README covers the database, persistent browser VM, encrypted configuration, first local account and Gmail connection.

Start with a preparation-only trial and review the résumé and missing answers. A complete unattended application has not yet passed testing. CAPTCHA solving is disabled.

The internal plugin namespace remains jobpilot for compatibility with the inherited runtime. The upstream JobPilot marketplace installer is not an OpenApply installer.
