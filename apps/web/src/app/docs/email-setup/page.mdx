# Email setup

Connect Gmail through your chosen agent. OpenApply imports the messages the agent reads; the provider manages Gmail authorization. You do not need to create a Google Cloud project or enter a client secret in OpenApply.

## Claude Code

1. Connect the intended Gmail account at [Claude connectors](https://claude.ai/customize/connectors).
2. In OpenApply's agent terminal, use `/login` to sign in with that same Claude account and subscription.
3. Open `/mcp` and confirm Gmail appears. Restart the agent if you just connected it.

Claude Code inherits claude.ai connectors with subscription login. API-key authentication and `claude setup-token` credentials do not load them. Use `/status` to check the active login. Anthropic's Gmail connector must be authorized on claude.ai; adding it as a local OAuth server does not work. See [Claude Code connector setup](https://code.claude.com/docs/en/mcp#use-mcp-servers-from-claudeai).

## Codex

1. Sign in to the embedded Codex terminal with the intended ChatGPT account.
2. Open `/plugins`, find Gmail, install or enable it, and complete any account-connection prompts.
3. Restart the agent after installation. Use `/apps` to find Gmail and `/mcp` to inspect the tools available to this session.

An installed plugin or a connection in another chat does not by itself verify this session's access. Availability depends on the account and runtime. See [Codex plugins](https://learn.chatgpt.com/docs/plugins) and [CLI commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli).

## Check in OpenApply

Open **Settings → Email**, or the workbench's **Connections** tab. Select **Check Gmail with Claude Code** or **Check Gmail with Codex** for your current agent.

The `connect-email` skill verifies the mailbox identity and imports recent job mail. It does not classify messages or send email. Only a successful import creates the OpenApply connection; an empty batch is valid after a successful search finds no new mail. The displayed last-sync time records that success, not a guarantee that the provider is still authenticated. Use **Scan pending** in the inbox when you want classification.

## Verification and replies

The agent pulls new mail for verification codes and checks the recipient, sender, employer and request time. Missing access or an ambiguous message parks the application and asks for help.

Approved interview replies use the connector send tool. Connector accounts cannot use OpenApply's OAuth sync or send endpoints. These return a clear conflict error directing the agent to its connector.

## Existing OAuth accounts

If a legacy Google OAuth mailbox is already connected, disconnect it in **Settings → Email** before checking the agent connector. Existing OAuth records remain supported by the backend. Google sign-in for your OpenApply account is separate from Gmail access.

Do not paste passwords or connector tokens into the agent conversation. Authenticate through the connector's own setup flow.
