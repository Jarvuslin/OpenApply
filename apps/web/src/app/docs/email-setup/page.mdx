# Email setup

Your local Claude Code or Codex agent reads Gmail through its own connector. OpenApply stores the normalized messages and application history. This path does not require an OpenApply Google Cloud OAuth app.

## Connect the running agent

1. Connect the intended Gmail account in the agent runtime that OpenApply starts.
2. In Claude Code, use `/mcp` to confirm Gmail tools are available. The job-worker allowlist must use the actual tool prefix. A connector available in another chat may not be available here.
3. Open the workbench's **Connections** tab and click **Check Gmail connection**.
4. The agent checks its mailbox identity, reads recent job mail and uploads messages through the authenticated ingest endpoint. A successful first upload creates the connector account.

The backend ingest path is tested. Access from a fresh embedded worker still needs a live test with your installed connector. An account showing as connected means an upload succeeded, not that future connector calls are guaranteed.

## Verification and replies

The agent pulls new mail for verification codes and checks the recipient, sender, employer and request time. Missing access or an ambiguous message parks the application and asks for help.

Approved interview replies use the connector send tool. Connector accounts cannot use OpenApply's OAuth sync or send endpoints. These return a clear conflict error directing the agent to its connector.

## Existing OAuth accounts

If a Google OAuth mailbox is already connected in **Settings → Email**, disconnect it before switching to the agent connector. Existing OAuth routes and encrypted records remain supported. Google sign-in for your OpenApply account is separate from Gmail access.

Do not paste passwords or connector tokens into the agent conversation. Authenticate through the connector's own setup flow.
