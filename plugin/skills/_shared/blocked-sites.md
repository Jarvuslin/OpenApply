# Employer applications only

Never open, log in to, create an account on, or apply through LinkedIn, Indeed, Glassdoor, ZipRecruiter, Upwork, Handshake, or Wellfound in the browser. This includes their subdomains and country sites.

Discover these listings only through the API's opt-in HTTP connectors. Use the resolved employer apply URL. A missing employer URL stays visible in Discover but cannot enter the apply queue. Do not follow an employer page redirect onto a blocked board. Stop that job and record why.

The user's own LinkedIn profile URL may be entered into an employer form field. It is applicant data, not a navigation instruction.
